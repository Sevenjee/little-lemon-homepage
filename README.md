# 🍋 Little Lemon Restaurant — Homepage

A fully responsive restaurant homepage built as the final project
for the **HTML and CSS in Depth** | Course 4 - module 3 | course on Coursera by **Meta**

## Features
- Semantic HTML5 structure
- CSS Flexbox 3-column card layout
- Animated hero banner (CSS keyframes)
- Active navigation state
- Open Graph meta tags
- Favicon implementation
- Responsive design with media queries (tablet + mobile)

## Technologies Used
- HTML5
- CSS3 (Flexbox, custom properties, animations, media queries)

## 📌 Future Improvements
Add booking functionality with JavaScript
Improve accessibility (ARIA labels)
Add a full menu page

## 🎯 What I Learned
Building semantic layouts using HTML
Using Flexbox for layout design
Applying media queries for responsiveness
Creating modern UI with hover effects and animations
